# Ohay

**Apprendre, comprendre, avancer.** Application d'apprentissage ludique pour les élèves malgaches, de la 6ème à la Terminale, avec Haiko, la mascotte.

▶ **Ouvrir Ohay : https://trakotomalala-droid.github.io/ohay/**

## L'installer sur son téléphone
- **iPhone :** ouvrir le lien dans Safari › bouton Partager › « Sur l'écran d'accueil » › Ajouter.
- **Android :** ouvrir le lien dans Chrome › menu ⋮ › « Installer l'application ».

Une fois ouverte une première fois avec internet, l'app fonctionne sans connexion.

## Contenu
- `index.html` : l'application complète (une seule page)
- `manifest.webmanifest`, `sw.js` : installation sur le téléphone et fonctionnement hors connexion
- icônes de l'app
